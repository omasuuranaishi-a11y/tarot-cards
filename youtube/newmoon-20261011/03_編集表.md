# 2026年10月11日 天秤座新月｜編集表（全編 v3 の実装）

`full-v3/index.html` の全編（約26:08・94場面）を、場面ごとに書き出した表です。
`tools/make_edit_table.py full-v3` で `full-v3/timeline.json` から作っているので、画面の定義（`full/chapters.js`、`full-v2/v2.js`、`full-v3/v3.js`、`tools/stock.tsv`）を変えたら作り直してください。

## 共通ルール

v3 で変えたこと：
- 挿絵のうち6か所（04-3、05-7、09-4、09-6、11-8〜11-9、13-4）を、Mixkit の無料の実写素材に差し替えた。文字・字幕・ワイプ・時刻は v2 と同じ
- 実写の場面には、左上の見出しの下に小さく「イメージ」と入れる。当日の空や本人の体験ではない
- 実写は彩度を少し下げ、暗い紫のグラデーション（上 .25 → 下 .55）と周辺減光を重ね、1.00→1.05 倍へゆっくり寄る。場面のつなぎは今までと同じクロスフェード
- 素材より場面が長いところは 0.5〜0.7 倍のゆっくり再生にし、足りない分は最後のコマで止める（ループはしない）
- 素材は GitHub に入れていない。`tools/fetch_stock.sh` で `stock/` に取得してから書き出す（一覧は `tools/stock.tsv`）

v2 で変えたこと（v3 も同じ。`reference/参考動画の分析.md` の提案から）：
- 字幕は太いゴシック48px（画面の高さの約4.4%）。読点で区切り、1行24字・2行までの塊で出す。かぎかっこの中では区切らない
- 第2章からは、章の頭に2.6秒の章タイトル（「第○章」と明朝68pxの題、金の細い線）を入れる。この間は読む文がない
- 冒頭（01-1〜01-2）はサムネイルと同じ表紙の画面で、あいさつと今回のテーマを読む
- 天体どうしを結ぶ線は4.5px以上にして両端に金の点、同じ度数で重なる太陽と月は金の輪で一つに囲む
- 注釈の数値（度数・角度）は36pxに大きくする。画面の下に置いた文字は、字幕と重ならないよう少し上げる
- 締め（13-3〜13-4）に、チャンネル登録のひとこと・問いかけ・コメント欄への誘いを文字だけで入れる（読む文は変えていない）

v1 から続くルール：
- チャートは「全体 → 該当天体を拡大 → 線を描く → 度数・オーブ → 象徴と解釈 → 具体例 → 図に戻る」を基本にする
- 見出しは明朝、度数と説明はゴシック。文字は小さく上へ動きながら現れ、静かに止まる。場面はクロスフェード（0.8秒）でつなぎ、暗転は使わない
- 右の説明パネルが出ている間は、チャートの右端をぼかして文字と重ねない。字幕は画面下の帯に入れる
- ワイプは右下に丸いアイコンを置き、名前と中心をそろえる。挿絵・比較図の場面では下げる（あいさつと締めは出す）
- 日常の例の場面には「日常の例です。配置が出来事を決めるわけではありません。」と小さく入れる
- 天体の位置・度数・ハウスは計算値からの作図だけを使う。前回の満月の図も同じ計算（承認済みの値と一致）で描いている
- 長さは毎分330字＋図を見せる間の仮の値。録音後は各単位の長さを実際の音声に合わせる
