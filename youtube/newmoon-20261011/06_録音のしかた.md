# 録音のしかたと、動画への合わせ方（全編 v4）

全編 v4 は、**おますさん本人の声**でナレーションを入れます。
AIの声（本人の声をもとにした読み上げ）も試しましたが、イントネーションの直しが多くなるため、本人の録音に切り替えました（2026年10月3日）。

## 渡すもの

| もの | 場所 | 使い方 |
|---|---|---|
| 録音用の台本 | `recording/台本_録音用.pdf`（作り直しは `python tools/make_teleprompter.py` → `node tools/html2pdf.mjs recording/台本_録音用.html recording/台本_録音用.pdf`） | スマホで読みやすい大きな文字。1文1行、章ごとに改ページ。中身は `02_録音台本.md` と同じ |
| 録音ガイドの動画 | 章ごとに13本（`full-v3/newmoon-full-v3.mp4` を章の時刻で切り、720p・音なしにしたもの。GitHub には入れていない） | 画面と字幕を見ながら話したいときに使う。**タイミングは合わせなくてよい** |

## 録音のしかた

1. **動画に合わせなくて大丈夫です。** 台本を、自然なペースで読んでください。画面の動き・字幕・口の動きは、あとで声に合わせます。
2. **章ごとに1つのファイル**で録ります。ファイル名は章の番号（`01`〜`13`）。1本にまとめて録っても使えます（ファイル名の順に、続けて読んだものとして扱います）。
3. 段落の間（台本で行が空いているところ）は、1〜2秒あけます。
4. **読み間違えたら、止めずに、その文の頭から読み直してください。** 後の読み直し（最後に読んだほう）を使います。段落の頭から読み直しても大丈夫です。
5. スマホのボイスメモで十分です。静かな部屋で、口とスマホは20〜30cmくらい。エアコンや換気扇の音はできれば止めます。
6. 録り終えたら、このセッション（または制作のセッション）にアップロードします。

## 動画への合わせ方（作る側の手順）

録音は `narration/` に置きます（`.gitignore` 済み。録音・声から作ったもの・音声付きの動画は GitHub に入れない）。

```
python tools/build_narration.py stt      # 文字起こし（fal の ElevenLabs、言葉ごとの時刻つき。約 0.03ドル/分）
python tools/build_narration.py align    # 台本の各文が録音のどこかを決める → full-v4/narration.js、narration/clips.json
node tools/export_layout.mjs             # 各文を置く時刻 → narration/layout.json
python tools/build_narration.py mix      # 各文を置いた音声 narration/narration.wav、口の開き full-v4/mouth.js
FFMPEG=ffmpeg bash tools/fetch_stock.sh  # 実写素材（まだなら）
CRF=21 node tools/render.mjs video full-v4/index.html full-v4/part0.mp4 1920 1080 30 <開始秒> <終了秒>   # 区切って並行に書き出し、concat でつなぐ
python tools/build_narration.py mux full-v4/video.mp4 full-v4/newmoon-full-v4.mp4   # 音を整えて（約 −16 LUFS、AAC）重ねる
```

- **対応づけ（align）**：台本の文と文字起こしを、表記ゆれ（数字と漢数字、カタカナとひらがな、MC とエムシー など）をそろえてから比べます。同じ文が2回あれば後のほうを使います。一致が85%未満の文は「要確認」と表示するので、その文は耳で確かめます。
- **時刻**：各文の長さは録音の実測（頭と尻の無音は音の大きさで詰める）。文と文の間は録音の間を 0.25〜0.9 秒に収めたもの。単位の終わりの「図を見せる間」（`pad`）と章タイトル（2.6秒）は v3 と同じです。
- **画面**：画面の動きは各文の開始時刻（`T.s(k)`）に結びついているので、実測の時刻に合わせて一緒に動きます（`lib/engine.js` の `E.opts.narration`）。
- **口**：音声の大きさで動かします（`E.opts.mouth`）。「口の動きは仮」の表示は消えます。
- **ずれの確認**：試験用の音（台本の長さに合わせた合成音と、読み直しを2か所入れた文字起こし）で通したところ、255文すべてが対応づき、声の始まりは字幕の 0.05 秒後、終わりは字幕の終わりの 0.14 秒以内でした。本番の録音でも、全編の書き出し後に数か所を再生して確かめます。
