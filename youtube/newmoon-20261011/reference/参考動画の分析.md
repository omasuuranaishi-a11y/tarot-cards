# 参考動画の分析（Maya Arikaの覚醒channel）

## 結果：YouTube に接続できなかったため、分析は行っていません

- 確認日時：2026-09-27 08:21 UTC ごろ
- この環境の外向き通信プロキシが YouTube 関連ホストへの接続を拒否しました（組織ポリシーによる拒否、またはプロキシの先に届かない）。
- 動画・字幕・サムネイル・ストーリーボードのどれも取得できていないため、**実際に見て確かめたことはありません**。推測で分析を書くこともしていません。

### 実行したコマンドとエラー（そのまま）

```
$ curl -sS -o /dev/null -w "%{http_code}" https://www.youtube.com/
curl: (56) CONNECT tunnel failed, response 403
000

$ curl -sS -o /dev/null -w "%{http_code}" https://i.ytimg.com/
curl: (56) CONNECT tunnel failed, response 403
000

$ curl -sS -o /dev/null -w "%{http_code}" https://m.youtube.com/
curl: (56) CONNECT tunnel failed, response 403
000

$ curl -sS -o /dev/null -w "%{http_code}" https://www.youtube.com/watch?v=iEmad_Gq4Zk
curl: (56) CONNECT tunnel failed, response 403
000
```

プロキシの記録：

```
kind: connect_rejected
detail: gateway answered 403 to CONNECT (policy denial or upstream failure)
host: www.youtube.com:443
```

## 考えられる原因と次の手順

- ネットワーク設定の変更は、**変更後に新しく立ち上げたセッション**から効くことが多いです。このセッションのコンテナが設定変更より前に起動していた可能性があります。
- 環境の設定（セッション上部の環境メニュー → Edit → Network access）で、`www.youtube.com`・`m.youtube.com`・`*.youtube.com`・`i.ytimg.com`・`*.googlevideo.com` が許可ドメインに入っているかを確かめてから、**新しいセッション**で同じ依頼をやり直してください。
  - 説明ページ：https://code.claude.com/docs/en/claude-code-on-the-web
- 制作本体のセッションへ：このファイルにはまだ分析内容がありません。動画の修正には使わないでください。
